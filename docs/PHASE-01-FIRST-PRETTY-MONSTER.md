# Phase 01 · FIRST PRETTY MONSTER

**Status:** Source committed and pure-JavaScript logic checks performed. Real iPhone Safari, Canvas2D rendering and GitHub Pages hosting still need hands-on visual QA.

## The first playable studio
- Three causally different material growth laws: **Polarized Rosettes**, **Electric Dendrites**, and **Living Agate Strata**. Changing the law affects future births; existing deposited history is not cleared.
- Real rectangular physics: **square 192×192** or **portrait 144×256** independently simulated cells. Switching requires confirmation and begins a new world, not stretching/cropping an existing square.
- Four seed arrangements, variable founder count/coverage/speed, live pause, fingertip planting of independent founder families, real lineage boundaries, retained birth-phase and age data.
- Material appearance: crystal shimmer, liquid enamel or velvet matte; independent edge contrast, depositional detail, electric color boost, glow, background, and pigmentation phase.
- All 199 source-authored original MATHEMAGICAL + EX NIHILO palette records, exact names and color stops. Search, pick, randomize or shuffle. Color treatment is a reversible *view* over preserved mineral state; no claim that these are physical pigment changes.
- Surprise Me mutates independent composition, law, color, material and framing parameters; editable afterward. New Design and aspect switching have confirmation; the previous whole world can be restored with one-level Undo.
- **Local PNG** of the device-sized canvas and local full living-world JSON save/load (source RNG, occupancy, frontiers, birth bands, current art settings).
- Small mobile-first tabbed UI with adjustable pinned artwork height.

## Where to play
- **Primary:** repo-root \`index.html\` through GitHub Pages after the artist enables **Settings → Pages → Deploy from a branch → main / (root)**. Expected URL: https://merrypranxter.github.io/mattergasm/
- **Offline downloadable:** \`previews/phase-01-standalone.html\` embeds every runtime module and all 199 palettes into one file, without imports/CDNs/network access. GitHub source/blob viewer does NOT execute HTML; download the raw file and open in a real JS-enabled browser. On iOS, Files Quick Look behavior may vary; Pages is the reliable phone-preview route.
- Neither path calls Netlify or a paid API. No Netlify deployments, Pages configuration changes, or GitHub Actions workflows were initiated here.
