# MATTERGASM — 15-Phase Artistic Roadmap
**Dated:** 2026-11-15
**Planning status:** Phase 00 only. User will advance phases with “Next”.
**North star:** The process of matter organizing itself should generate exquisite, wildly varied, powerful abstract art, not just an interesting growth demonstration.

## Rules applying to *every phase*
1. **Free HTML preview:** Commit runnable, browser-accessible `index.html` (or an explicit linked `previews/<phase>.html` prototype) and keep the prior gallery accessible; hand the user a direct playable link once GitHub Pages is enabled. Where practical, also make a single standalone HTML attachment that opens without a build tool. Never require Netlify.
2. **No paid services/deploys:** No Netlify, no paid APIs, no automatic preview-build services. Keep it all client-side / GitHub-hosted. GitHub Pages **public repository**, branch-publishing from `main` `/(root)`, once Phase 01 creates an entry point. Standard Pages and public repo standard runners are free within limits; still monitor GitHub quotas and avoid build spam.
3. **Visible progress:** Every phase must produce a visually inspectable change and interactive control, not just preparatory infrastructure.
4. **True generative mechanisms:** Engines must change living state or derive render geometry from genuine history, not merely rebrand the same shader or recolor the same silhouette. Preserve clear role boundaries between growth, microstructure, optics, composition and export.
5. **Protect the artist:** All 199 original palettes (194 MATHEMAGICAL and 5 Ex Nihilo), eventually exact source color stops, customization, editable Surprise Me, saved DNA and living checkpoints, New Design confirmation, Undo/Redo, thumb-sized touch, portrait/square native composition.
6. **Honesty:** Distinguish simulation resolution from render/export detail; realistic optics from illustration; closed animation phase from actual encoded MP4 timing; testable code from device-verified behavior.
7. **Source separation:** Do not modify either original Ex Nihilo repo. Reuse or adapt code narrowly and only in Mattergasm, verifying API assumptions and code provenance.
8. **One Next = one deliverable:** Small, reversible commits; do not open pull requests unnecessarily; no accidental Netlify deploy triggers. If a phase is too large, explicitly number bounded subphases while preserving the roadmap.

## ARC I — Birth of beautiful matter
### Phase 01 — FIRST PRETTY MONSTER
**Deliver:** No-build playable mobile-first HTML prototype (root `index.html`) with actually evolving competitive mineral growth; polished generative rosettes/territories/strata; square and *native-composition* 9:16 art; at least three different starter structures with strongly different silhouettes. Art begins as a beautiful composition. Native animation, pause/reseed, deterministic seed, true Surprise Me, basic palette choosing, safe mobile tabbed UI.
**Proof:** Touch makes a visual change, seeded restart reproduces composition, portrait is not merely stretched, all relevant controls do something; `index.html` can publish as GitHub Pages without Netlify.

### Phase 02 — COMPOSITION WITCH
**Deliver:** Spatially effective birth constraints: void islands, arched windows, branching rivers, orbit/ribbon boundaries, multiple colony scales and distribution. Artist can shift visual balance and negative space, not just choose a seed arrangement. Monochrome structure audit.
**Proof:** Same seed and palette with different composition law yields provably different occupied cells and final large-scale silhouettes.

### Phase 03 — GESTURE WITCH
**Deliver:** Plant nuclei; attract/repel/comb growth; protect blank space; add fractures; distinct one-finger editing vs two-finger view manipulation; Undo/Redo; safe cancel rollback and destructive reset confirmation.
**Proof:** Each gesture changes next real births and survives checkpoint; undo restores state; device interactions inspected when possible.

### Phase 04 — POLARIZED FEVER DREAM
**Deliver:** Signature birefringence-*inspired* rendering rooted in crystal orientation, age, relief and family. Rotating crossed analyzer, opaline interference, prismatic and flat pop-art aesthetics. Strong deliberate tonal contrast, not rainbows smeared indiscriminately on top.
**Proof:** With material history frozen, polarizer changes appearance and not births; same seed different orientation produces distinct optical response; optical 2–3 s phase is closed.

### Phase 05 — MICROMATTER
**Deliver:** Morphology-tied high-detail platelet lamellae, filament venation, crystalline vesicles, microcracks, facet lines and fine glints, computed at display/export resolution where feasible. Distinct real sub-cell geometry, preview/export quality controls.
**Proof:** High-res zoom reveals fine structure tied to lineage/depth/stress and no fake claim of a high-resolution CA.

### Phase 06 — FIRST POSTABLE LOOP
**Deliver:** Polished still PNG, portrait/square GIF, local deterministic periodic render for moving light, pigment films and optical effects. Scrubber, basic camera framing, safe budget guards, encoder diagnostics. Try feature-detected true MP4 only if browser supports it, never mislabeled WebM.
**Proof:** A 2–3s GIF plays and loops; scene history is unchanged by export; output aspect and duration valid. Real iPhone and TikTok/CapCut video performance must be checked before certification.

## ARC II — Five new art species
### Phase 07 — LIVING LACE PLAGUE
**Donors:** Ex Nihilo morphogenesis / `belousov_zhabotinsky` / `slimemoldartapp`.
**Deliver:** Reaction-wave or excitable chemistry fronts cause persistent mineral filament deposition, and deposited filaments can constrain subsequent chemistry; protective simulation pacing controls.
**Proof:** A distinct lacy/tunnel morphology emerges in monochrome; comparing causal feedback on/off changes later state, not only shading.

### Phase 08 — CANDY FAULT BROCADE
**Donors:** `strataclysm`, `crystal_math_art`, `impossibleloom`.
**Deliver:** Stratified mineral layers retain strain, fault on thresholds and grow luminous stitching/fibers along real structural stress and cleavage geometry.
**Proof:** Rifts persist in saved history, stitches respond to stress, and outputs do not resemble the Phase 07 lace family.

### Phase 09 — QUASICRYSTAL SYNAPSE
**Donors:** `phason_riot`, `lightloom_art`, `impossibleloom`.
**Deliver:** Quasicrystal network with live excitation propagating through actual adjacency, node histories causing new crystalline growth and point-light filaments; controlled optional chemical/electric feedback.
**Proof:** Switch topology while holding palette fixed and observed graph/signal/occupancy evolution differs; no arbitrary texture overlay.

### Phase 10 — MOLTEN PARADISE
**Donors:** `liquid_light_show`, `frothrot`, `caustic_art_app`.
**Deliver:** Flow/phase-separation and foam boundaries guide permanent precipitation; solid material constrains subsequent flow; optical caustic finish follows actual structures. A lightweight reliable iPhone tier first.
**Proof:** Flow affects matter births and age; low-power rendering remains interactive without invoking a remote server.

### Phase 11 — PHENOMENON PATCHBAY
**Deliver:** Mix compatible species with typed ports for scalar fields, direction fields, masks, graphs, microstructures, and light; artist-controlled cause-and-effect relationships, OFF defaults and safe rollback. Use Handoff Blacksmith + Causality Switchboard reasoning for actual interoperable feedback.
**Proof:** ON/OFF same-seed experiments demonstrate genuine future-state differences, adapters state sizes/coordinates/clocks/wrap and never silently convert incompatible data.

## ARC III — Evolution, direction, and theatrical beauty
### Phase 12 — MUTANT NURSERY + SURPRISE ME 2.0
**Deliver:** Show four genuinely different children (not just colorways); choose or breed source DNA across morphology, composition, microstructure, material and choreography; preserve champion works. Expand Surprise Me to cover all newly added independent behaviors while keeping full editable controls, custom weights, selected parent traits and reproducible seeds.
**Proof:** Offspring measurably differ structurally in monochrome; each can be adopted as editable ongoing world without deleting source parents.

### Phase 13 — ART DIRECTOR + LIVING COMPOSITIONS
**Deliver:** Hierarchical multi-scale patterns, intentionally placed focal attractions, sparse/packed regions, negative-space shape drawing, selected region-scale symmetry/asymmetry, layered matter types with separate histories, animation reveal choreography, native 9:16 TikTok composition templates.
**Proof:** Author can reproduce several dramatically distinct image compositions at the same color palette using structural decisions alone.

### Phase 14 — MASTER MATERIAL + COLOR ALCHEMY
**Deliver:** All existing named exact palettes; editable swatch stops, favorites, remix, shuffle, warm/cool, neon/electric saturation; family-specific pigments and before/after lighting; optical modes from matte poster inks through wet glass, opal, polarizing crystals, spectral oil and luminous textile. Source colors and physically generated colors remain controlled independently.
**Proof:** Named palettes match source entries, changing lights cannot mutate stored birth pigments, random palettes never corrupt a saved design.

### Phase 15 — LOOP FORGE II + POLISH / RELEASE
**Deliver:** Offline or supported encoder pipeline for high-quality GIF and native H.264/MP4 if viable in Safari; 1:1, 9:16 and optional 16:9/3:4/4:3. 2/3/5/10s closed motion, optional boomerang for non-periodic sequences, 30s cinematic capture if practical. Render-from-snapshot, no frame-timing/simulation-speed coupling, seam inspector, source color/gradient GIF palette improvements. Final pinned/resizable iPhone stage, simplified tabs, guide overlays only in preview, art-first gallery.
**Proof:** Source-loop seam tests and decoded-file validation; actual iOS Safari/Photos/CapCut/TikTok manual QA for MP4; no expensive service required. Report unsupported codecs rather than claiming successful export.

## Free HTML preview protocol
- **Phase 01:** ship a single-file playable art stage where practical; root `index.html` is source of truth for Pages.
- **Each Next:** change the actual app, maintain or add `previews/phase-NN.html` when a separate experiment is safer, and return a real playable link only after its path and publication are verified. For standalone previews, supply an actual generated local `.html` file when current execution tools support creating it.
- **Not a fake preview:** controls must alter real state/art; no static mock that pretends to operate. If a full simulator cannot fit a standalone file, link to the real deployed JS-backed Pages app and clearly describe the limitation.
- **GitHub Pages source:** `main` `/(root)`, public repo, simple HTML/JS + relative assets; use `.nojekyll` if needed. Pages deployment is a GitHub-only static publish, not Netlify; the artist must enable Pages in repository settings.
- **Publishing costs:** free for this ordinary public art demo within GitHub Pages limits (site 1GB, bandwidth soft 100GB/month, branch publish 10 builds/hour soft). No promises that other paid features or storage overages are free.
- **Artifact provenance:** phase status values `proposed | source-written | logic-tested | browser-tested | iPhone-tested | export-verified`; never say tested without observed evidence.
